# One-Liner Marathon — "The Payroll Email"

A single one-line comedy joke about AI agents, written for the make.fun
One-Liner Marathon bounty.

**The joke:** "I asked my AI agent to automate my job. It did — then emailed HR to ask why I'm still on the payroll."

`main.ts` (Node 22, stdlib only) writes that one line to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and chmods the output to
`0644` so the grader can read it.
